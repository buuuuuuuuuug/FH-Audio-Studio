# FH Audio Studio 1.0 Preview 2

版本标签 `v1.0.0-preview.2`，应用版本 `1.0.0-preview.2+91`。

## 主要更新

- **GPT-SoVITS 语音生成**：独立安装推理环境或连接同机 API，无需 GAG；管理 GPT／SoVITS 模型、主／辅助参考、语言和声音预设，支持批量生成、重试、试听、编辑和导出。
- **直接生成并替换**：在语音替换工作区按原文或显示语言生成，成功后采用到草稿；可取消应用、删除文件和继续编辑，保存后再构建。生成不直接写入游戏。
- **引擎安装与维护**：仅安装推理所需组件；提供官方及国内下载源、断点续传、阶段进度与速度、后台安装、暂停继续、手动准备、组件检查和删除引擎。API 连接状态与声音配置分别检查。
- **游戏更新兼容**：重新检查资源指纹，复用可用解析缓存；保存现有制作与歌单。写入时省略相同文件，阻止过期准备包覆盖已更新资源；语言偏好与文本压缩包不写回游戏。
- **界面与操作**：整理三栏布局、导航收放、搜索与多选，统一音频编辑、快捷键和生成状态；补充语音生成五步介绍与替换页首次生成引导。
- **修复与文档**：修正包清单写入时项目路径判断不一致、旧预设原文件名恢复等问题；精简 README，更新详细功能、配置说明及新截图。

## 下载与升级

Windows x64 便携包包含基础 Python 运行环境、uv、核心音频工具及 SeamlessLoopMusic。**完整解压到新英文目录**，运行 `fh-radio-studio.exe`，然后打开已有工程；不要只复制 EXE。

包内不包含个人工程、声音预设、导入模型、参考音频、生成结果或 GPT-SoVITS 引擎。语音生成默认开启，首次使用按界面引导安装或连接 API，并自行导入声音模型及参考音频。安装体积和依赖会在界面中提示。

歌曲和台呼共用准备包，其他语音使用独立准备包。写入前退出游戏，核对文件清单；建议保留原应用目录及工程备份，检查新版后再清理旧程序。

## 检查范围与限制

发布前完成 Flutter 静态检查、Windows 构建及自动化回归：前端 834 项通过、16 项按运行条件跳过，后端 631 项通过。便携包已检查内容与校验值，并验证基础 Python 环境的离线初始化、命令执行及窗口启动。

- 未在本次准备中写入真实游戏，游戏内听感和长时间运行仍需人工验收。
- 不对全部 GPT-SoVITS 模型家族、CPU 推理或所有网络环境保证兼容。镜像和官方服务的可用性会变化；失败时可切换来源或手动准备。
- 新版不改变游戏事件触发规则；替换音频仍可能受到原事件播放窗口限制。
- 电台扩容、分场景编辑与语音生成仍为实验功能，分场景编辑依赖扩容。
