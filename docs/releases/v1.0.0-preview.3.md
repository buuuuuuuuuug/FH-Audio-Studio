# FH Audio Studio 1.0 Preview 3

版本标签为 `v1.0.0-preview.3`，应用版本 `1.0.0-preview.3+93`。

## 主要更新

- **RVC 音色转换**：在语音生成页面切换 GPT-SoVITS／RVC，导入已有录音，或在语音替换中直接使用游戏原音转换音色。支持单条、批量、暂停、取消、重试，以及结果试听、波形编辑、导出和采用为替换草稿。
- **音色配置与预设**：导入 RVC v1/v2 模型及可选配套索引，选择 CPU／NVIDIA CUDA，调整音高提取、变调、检索比例、辅音保护等参数。支持完整预设的保存、另存、切换、删除和未保存标记；导入文件保留原名。
- **独立推理环境**：仅按需安装 RVC 推理组件，与 GPT-SoVITS 环境隔离。提供官方／镜像源、组件检查、阶段进度、下载速度、暂停继续、后台安装、控制台及引擎删除。
- **介绍与参数说明**：补充 RVC 工作台和语音替换的首次使用介绍；RVC 与 GPT-SoVITS 参数提供悬浮说明，模型状态可直接打开引擎设置。

## 下载与升级

完整解压 Windows x64 便携包，运行 `fh-radio-studio.exe`，再打开已有工程。歌曲、台呼、语音替换和 GPT-SoVITS 保持原有工作流。不要只复制 EXE。

便携包附带基础运行环境、核心音频工具和 SeamlessLoopMusic，不包含个人工程、游戏资源、音色模型、参考音频、RVC 或 GPT-SoVITS 的推理安装目录。两种语音引擎均按需安装；RVC 需要自行导入有权使用的音色模型。

2026-11-15 本地发布前检查：前端 865 项通过、16 项按条件跳过，后端 655 项通过；静态检查、提交格式检查与 Python 编译检查通过。新增回归覆盖 RVC 未安装、安装完成和卸载后的界面切换，以及窄窗口、深浅主题、引擎设置入口和两种引擎卡片的一致性。Windows 构建、包内容、启动与离线运行检查见本地验收记录。

- CPU 实际转换、索引转换和游戏语音条目采用流程已在此前独立测试包中检查；本轮完整回归与新包检查单独记录。
- CUDA 设备和依赖安装流程已接入，尚未完成 CUDA 实机推理验收。
- 本次不写入真实游戏；游戏内音质、事件触发长度及长时间运行仍需人工确认。
- 本版不集成人声分离、降噪、去回声或训练功能。含背景音乐的录音建议先单独处理，再导入转换。
- GPT-SoVITS／RVC、扩容和分场景编排仍为实验功能；分场景编排依赖扩容。
