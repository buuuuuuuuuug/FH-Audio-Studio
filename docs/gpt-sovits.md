# GPT-SoVITS 语音生成

根据参考音频和输入文本生成语音，可试听、编辑、导出，或直接用于游戏语音替换。此功能仍为实验功能，声音模型和参考音频需自行准备。

## 1. 安装或连接引擎

进入「语音生成」，点击「推理引擎」，选择一种方式：

- **应用管理本地服务**：选择下载源，点击「安装或修复」；完成后先按下文导入 GPT 和 SoVITS 模型，再点击「启动服务」。下载失败可切换来源后继续，也可按「手动准备」中的说明下载文件。
- **连接已有 API**：先启动同一电脑上的 GPT-SoVITS `api_v2` 服务，填入地址和端口，再点击「测试连接」。默认地址为 `127.0.0.1:9880`。

安装完成或连接已有 API 后，继续配置声音。API 可用只表示服务已连接，不代表模型和参考音频已经配置完成。

## 2. 配置声音预设

1. 选择与模型对应的版本，分别导入 GPT 和 SoVITS 模型。
2. 选择生成语言与参考语言，导入一段 **3–10 秒**、清晰且尽量无背景音乐的主参考音频。
3. 填写参考音频中实际说出的文本。支持的模型也可勾选「无需参考文本」；辅助参考音频按需添加。
4. 点击「保存预设」，之后可直接切换使用。

参考音频会影响音色、语气与情绪。推理参数建议先用默认值，再根据试听调整语速等选项；修改预设后记得保存。

## 3. 生成、试听与编辑

在右侧输入文本，选择整段或分段生成、生成数量，再点击「生成语音」。效果不满意时可修改文本、参考音频或参数后重新生成。

点击结果展开波形：左键定位播放，右键拖动选区；可插入静音、静音或删除选区、调整音量，并撤销或重做。满意后点击「加入素材池」，也可直接导出音频。

## 4. 在语音替换中使用

1. 解析并选择要替换的条目，打开「语音生成」。
2. 选择声音预设，使用语音语言或显示语言文本，也可手动修改。
3. 点击「生成语音」，成功后会自动采用到当前替换草稿；试听并按需编辑。
4. 点击「保存修改」，再构建语音准备包、核对清单并写入游戏。

多选条目后可批量生成，并选择跳过已有替换。「取消应用」保留音频文件；「删除文件」会同时清理该文件对应的替换。**生成和保存不会直接写入游戏。**

## 遇到问题

- **下载失败或停滞**：查看安装进度与控制台，暂停后切换下载源，或使用「手动准备」。
- **API 无法连接**：确认服务已启动、地址与端口一致，再测试连接。
- **API 可用但生成失败**：检查声音配置，确认模型版本、参考时长、语言与参考文本；具体原因查看控制台。显存不足时可减小批次大小。

完整功能见 [功能介绍](Feature_Introduction.md)，引擎项目见 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)。
