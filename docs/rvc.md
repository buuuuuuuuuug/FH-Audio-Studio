# RVC 音色转换

在「语音生成」右上角切换「GPT-SoVITS／RVC」。GPT-SoVITS 根据文字生成语音，RVC 转换已有录音的音色，保留原句内容与节奏。

## 使用

1. 未安装时，点击居中引导卡片底部的「安装与设置 RVC 引擎」，选择 CPU 或 NVIDIA CUDA 及下载源，安装推理组件。安装完成后显示完整工作区；后续可通过「推理引擎」调整。切换设备后需要安装对应依赖；安装可暂停，关闭设置窗口可在后台继续。
2. 导入导出的 RVC v1/v2 `.pth` 音色模型，按需导入对应 `.index` 检索索引。GPT-SoVITS 模型、训练中间存档不能用于 RVC。导入会创建托管副本并保留原文件名。
3. 导入或拖入源音频，点击「转换音色／批量转换」。结果可以试听、编辑、加入素材池或导出。参数修改后自动记住，切换音色不会覆盖当前参数。音色、关联索引、推理设备和参数可保存为 RVC 预设，并在两处界面快速选择。
4. 在「语音替换」选择原音条目，打开「RVC」，选择音色与参数后转换。单条或多选批量使用相同的原音提取、替换草稿与保存流程；原资源编号和等待采用时的目标快照保留。

发布包不附带音色模型、索引或示例录音，请使用自己有权使用的模型与音频。说话人编号默认 0，多说话人模型可调整编号；编号必须在模型实际范围内。没有索引时，实际检索比例为 0，但保留设置的检索比例。

## RVC 预设与参数提示

保存预设会记录当前音色模型、配套索引、CPU/CUDA 设备及全部转换参数；修改后预设名旁显示 *，保存后有提示。下拉框可另存为新预设，删除预设不会删除模型、索引或音频。悬停参数旁的信息图标可查看说明。

## 关联索引与功能介绍

`.index` 是可选的音色特征检索文件，应使用模型作者提供的同一音色配套索引。转换时可利用训练音频的特征减少原说话人的音色残留；没有索引也能转换。检索比例为 0 时不参与检索，调高会增加训练特征的影响，也可能带入训练录音的噪声或其他瑕疵，应试听比较。未选择索引时，程序实际按 0 处理。

引擎已安装并选择音色模型后，首次进入音色转换会依次介绍引擎与设备、模型与索引、转换参数、源音频、转换结果。语音替换中首次使用音色转换，会介绍原音选择、转换与自动替换、试听与编辑。完成后不会自动重复，可通过右上角功能介绍再次查看。

关联索引说明参考 [RVC 官方 FAQ](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/wiki/FAQ-(Frequently-Asked-Questions)#q11what-is-the-index-rate-for-and-how-to-adjust-it)。

## 文件与运行

- RVC 引擎：`toolchain/engines/rvc/`，Python 3.10 与 GPT-SoVITS 的环境隔离。
- 模型与索引：引擎目录下 `imports/`，按内容校验去重，文件保留原始名称。
- 工程输入和结果：`analysis/voices/conversion/`；采用结果进入现有语音素材库。
- 删除推理引擎保留导入音色及工程音频；删除导入模型只移除托管副本。
- 暂停在当前条目完成后阻止后续条目开始；取消会终止应用自己启动的转换进程。异常、取消和未完成输出不会被采用。
- 只安装推理依赖，不包含训练页面、训练数据或 RVC-Fabric 桌面程序。
- 语音生成开关位于设置的功能区，同时控制 GPT-SoVITS 与 RVC 的入口；关闭保留已有模型、预设与素材。
