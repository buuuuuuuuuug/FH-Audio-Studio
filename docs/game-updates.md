# 游戏更新、备份与写入

原始备份是校验和恢复的依据，制作内容另存于工程中。更新备份不再清除播放列表草稿、歌曲时间点、台呼分配、语音替换、准备包或上次写入记录。

## 语言

显示语言读取 `%LOCALAPPDATA%/ForzaHorizon6/UserPreferredLang`，语音语言独立读取同目录的 `UserPreferredAudioLang`，不会把显示语言当成语音语言。设置缺失或为自动选择时沿用可用的工具配置作为后备，不将推断结果写回游戏。

这两个偏好文件和 `media/Stripped/StringTables/*.zip` 只读使用，不需要新建恢复备份，也不会随准备包或旧备份恢复操作写入。旧工程里的这类备份可保留，但会被排除在写入清单之外。

替换语音 bank 前保存的原音频快照仍然必要：用于原音试听、保持其他声音不变的重构、校验声音标识和恢复。它与只读语言偏好、文本压缩包是不同的资源。

## 更新时的处理

| 情况 | 处理 |
| --- | --- |
| 仅 Steam build 改变，受保护音频没变 | 保留制作；完整性检查继续区分版本变化与文件变化，不直接清空工程。 |
| 官方文件改变，旧 mediapc 覆盖仍在生效 | 独立检查底层 media 文件，提示更新，避免被旧覆盖文件掩盖。不会擅自删除游戏里的覆盖文件。 |
| 准备包构建后，相关游戏原文件更新 | 新包保存原文件指纹；写入前重新比对。不同则要求重建，保留原制作和旧包。旧包缺少指纹且已跨版本时拒绝直接复用。 |
| 游戏音频在构建期间改变 | 不发布这次结果，保留原准备包，等待更新结束后重建。 |
| 语音 bank 新增、重排条目 | 刷新原始快照与解析清单，按唯一声音标识匹配旧替换，不按旧序号直接套用；已保存和未保存草稿采用同一映射。 |
| 语音条目消失、标识重复或格式不支持 | 保留素材、原快照和迁移前记录；无法安全匹配的替换提示冲突并阻止构建，核对重新分配并保存后再构建。存档位于 `.fh-radio-studio/voices/history/`。 |
| 台呼原 bank / RadioInfo 更新 | 刷新对应原始快照，保留按 SoundName 关联的分配。失效的位置会阻止构建，需核对对应电台。历史记录位于 `.fh-radio-studio/stingers/history/`。 |
| 文本资源或显示/语音语言变化 | 文本索引按语言和资源签名失效并重新加载；语音资源扫描会列出新增文件。已解析资源更新时生成新清单和缓存。 |
| 第三方覆盖、未知修改或损坏文件 | 不把它自动当成官方更新；保持校验和冲突提示，不静默覆盖。 |

正常写入前逐文件比较准备包与游戏当前有效内容。相同文件不列为待写资源，也不会为它再复制一份覆盖文件；真正的替换、恢复或旧覆盖移除仍会列出。不同准备包的部署记录保留仍有效的已写入文件，用于识别自己的覆盖文件。

## 建议流程

1. 等待游戏更新结束，重新打开工具或刷新资源。
2. 概览出现文件变化时先核对；只有确认是官方完整安装或完整性验证后的文件，才更新原始备份。
3. 查看语音/台呼的迁移提示，重新分配失效条目并保存。
4. 重新构建相关准备包，检查实际变化文件清单，再决定写入。

应用只同步本地资源与制作关系，不会在 Steam 更新后自动向游戏写回旧内容。不能保证未来任何游戏版本都兼容；遇到声音标识或资源格式变化时会要求核对，避免错误套用。

## 文件名兼容

新导入的声音模型、参考音频、语音和台呼素材使用可读名称与短后缀；生成并采用的音频使用文本摘要。内容去重仍使用稳定 ID。旧哈希文件与引用继续兼容，不批量改名或删除撤销历史引用的旧文件；工程引用中的 URL 转义不等于磁盘文件名。
